# 속도 관련 용어

| 실제 대상 | 한국어 |
|---|---|
| generic.attack_speed | 공격 속도 |
| generic.movement_speed | 이동 속도 |
| minecraft:haste 상태 효과 | 성급함 |
| spell_power:haste | 주문 가속 |
| 투사체 velocity | 투사체 속도 / 화살 속도 |
| Momentum, 유도 acceleration | 맥락에 맞는 가속·가속도 유지 |

가속이라는 문자열을 일괄 치환하지 않는다. 스킬의 숫자 옆 표시는 실제 attribute 보상에, 상태 중첩은 실제 effect ID에 맞춘다. Ghaj는 바닐라 성급함을 사용하며 보조 손 단검은 생성이 아닌 장착 조건이다. 이번 검수 근거는 nightly-20261030.12 릴리스 설명에 기록했다.
