- 주문 HUD의 원래 아이콘·키캡·진행 음영을 사용합니다. 무기 쿨타임은 서버가 동기화한 실제 아이템 쿨타임을 읽습니다. 표시용 가짜 주문이나 새 쿨타임을 만들지 않습니다.
- 리비아탄 투척에는 긴 고정 타이머를 추가하지 않습니다. 자신이 던진 무기가 추적되고 손이 비어 있으면 귀환 대기로 표시합니다. 각성이 필요하거나 사용 중인 상태도 구분합니다.
- 기존 아이템 사용 표시와 중복하지 않으며, 보조 손의 원래 수정키도 유지합니다. 리소스팩·설정·서버 파일은 변경하지 않습니다.
