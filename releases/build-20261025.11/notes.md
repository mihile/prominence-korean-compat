BetterDays가 차원 이동·접속 종료 때 이전 월드를 다시 등록하던 두 호출을 바로잡았습니다. 파일명과 모드 버전 `1.0.0`은 유지합니다.

<details>
<summary>변경 내용</summary>

- 떠나는 월드는 원래 해제 함수로 처리합니다. 새 월드 생성 시 등록과 시간 보간 계산은 그대로입니다.
- Minecraft 1.20.1 / BetterDays 3.3.4.5의 원본 클래스 지문 네 개와 실제 콜백 형태가 일치할 때만 적용합니다.
- 추가 주기 작업, 강제 GC, 거리·화질·설정 변경이 없습니다. 기존 셰이더·배낭·소리 참조 정리와 모든 호환 기능을 포함합니다.
- 클라이언트 전용 변경입니다.

</details>

<details>
<summary>분석과 검증 범위</summary>

접속 전부터 5분 JFR을 정상 수집하고 기록 종료 후 별도 힙 덤프를 MAT로 분석했습니다. 이전 월드의 약147MiB 보유 경로에 잘못된 시간 보간 참조가 있었습니다. 이 수치는 분석한 객체 경로의 보유량이며, 실제 수정 후 전체 RAM 절감량은 아직 측정하지 않았습니다.

설치된 BetterDays와 Minecraft 바이트코드를 실제 Mixin으로 변환해 두 호출만 바뀌는지, 나머지 바이트코드와 새 월드 등록이 유지되는지 확인했습니다. 원본 콜백을 이용한 독립 수명 검사는 원래 오류를 재현하고 새 월드 보존·접속 종료·지연된 이전 월드 해제를 검증합니다. Minecraft·월드·OpenGL을 실행한 검사는 아닙니다.

첫 접속 EMI 초기화·셰이더 준비 비용과 다른 이전 월드 참조는 별도 개선 대상입니다. 이번 변경으로 접속 렉 전체가 해결됐다고 주장하지 않습니다.

</details>
