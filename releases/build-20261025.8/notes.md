Iris 셰이더 준비가 끝난 뒤 남는 분석용 중간 캐시를 정리합니다. 기존 기능과 파일명·모드 버전 `1.0.0`은 유지합니다.

<details>
<summary>변경 내용</summary>

- 파이프라인 생성 완료 시 Iris의 GLSL 구문 트리·토큰 캐시만 해제합니다.
- 컴파일된 GPU 셰이더, 변환 완료 소스, 작은 재사용 AST 캐시와 네이티브 LRU 용량은 유지합니다.
- 강제 GC, 셰이더 품질·거리·개인 설정 변경, Voxy 캐시 축소는 하지 않습니다.
- Minecraft 1.20.1 / Iris 1.7.6의 대상 클래스와 GLSL 구현 지문이 일치할 때만 작동합니다.

</details>

<details>
<summary>측정 근거와 검증 범위</summary>

실제 클라이언트의 차원 이동 후 힙 덤프에서 해당 파서 캐시 303개가 650,925,728바이트를 보유했습니다. 이 수치는 수정 후 확정 절감량이 아닙니다. 프로세스 전체 RAM에는 Java 힙 외의 렌더링 메모리도 포함됩니다.

실제 GLSL 파서 캐시·출력 검증 192개, 지문·대상 누락·비활성화 검증 4개, 기존 업데이트 검증 107개를 통과했습니다. 실제 Iris 바이트코드에 믹신을 적용해 생성자 호출 474개의 순서와 성공한 반환 지점 연결을 확인했습니다. 게임·OpenGL 재기동 후 RAM 감소량과 접속 지연 비교는 아직 미측정입니다.

첫 수집에서 힙 덤프가 접속 초기와 겹친 구간은 접속 시간 판단에서 제외했습니다. 후속 성능 비교는 힙 덤프 없이 기록합니다.

</details>
