차원 이동 뒤 남는 이전 플레이어의 채굴 입력과 이전 월드의 악기 연주 기록을 정리합니다. 파일명과 모드 버전 `1.0.0`은 유지합니다.

<details>
<summary>변경 내용</summary>

- Porting Lib가 보관한 마지막 채굴 이벤트 중 이전 클라이언트 플레이어의 것만 해제합니다. 현재 입력과 새로 생긴 이벤트는 유지합니다.
- Immersive Melodies의 연주 진행 맵에서 이전 클라이언트 월드의 엔티티만 제외합니다. 현재 월드와 서버 쪽 엔티티, 새로 교체된 연주 기록은 유지합니다.
- 월드나 플레이어가 실제 바뀔 때만 처리하며 매 프레임 맵을 지우지 않습니다. 실제 버전·클래스 지문과 필드 형태를 검사하고, 연동 실패 시 해당 보완만 비활성화합니다.
- 셰이더·배낭·소리·툴팁·BetterDays 수정과 모든 기존 호환 기능을 유지합니다. 서버나 설정은 변경하지 않습니다.

</details>

<details>
<summary>측정과 검증</summary>

접속 전부터 기록한 5분 JFR과 별도 사후 MAT 분석으로 확인했습니다. 앞선 BetterDays 수정은 실제 다음 게임에서 현재 월드를 참조하는 것으로 확인됐습니다. 이번에 정리하는 두 경로는 분석한 힙에서 각각 약86MiB·36MiB의 이전 월드로 이어졌으며, 이 수치를 전체 RAM 절감량으로 확정하지 않습니다.

34개 신규 검사는 실제 설치 모드의 진행 맵과 클래스 지문·필드 형태, 현재 상태 보존, 교체 중인 항목 보존, 참조 해제 후 객체 회수를 확인합니다. 기존 363개 클래스와 업데이트 도우미는 바이트 그대로 보존합니다. 새 수정의 실제 게임 동작과 RAM 회수량은 재시작 후 확인해야 합니다. 첫 접속 EMI·셰이더 준비와 다른 이전 월드 참조는 별도 개선 대상입니다.

</details>
