접속하면 새 패치를 확인하고, 게임 안에서 변경 내역을 바로 읽은 뒤 업데이트를 선택할 수 있습니다.

**처음 한 번은 게임을 끄고 아래 JAR을 `minecraft/mods`에 덮어써 주세요.** 이후에는 게임의 업데이트 안내를 사용하면 됩니다. 설치 파일명과 버전은 `prominence-korean-compat-1.0.0.jar` / `1.0.0` 그대로입니다.

<details>
<summary>✨ 게임 내 업데이트</summary>

- 변경 내역을 바로 표시하며, 길면 스크롤해서 읽습니다.
- **업데이트 / 나중에 / GitHub** 중 선택합니다.
- 다운로드·검증이 끝나면 계속 플레이하거나 게임을 종료할 수 있습니다.
- 게임 종료 후 교체하고 다음 실행부터 적용합니다. 기존 파일은 백업합니다.
- `/kpatch update`, `/kpatch auto on`, `/kpatch auto off`를 지원합니다.

</details>

<details>
<summary>🧩 누적 호환 기능</summary>

기존 한국어 문구·책·툴팁·조작키 보완, 화살통 스킬 호환, 대장장이 정보 보존, 정교한 배낭 작업대·모루·재단조 연결, EMI와 나침반 검색 및 광맥 생성 안내를 유지합니다. 자동 업데이트가 추가됐다고 앞선 기능을 뺀 작은 JAR로 교체하지 않습니다.

일부 기능은 대응 리소스팩·퀘스트 파일 또는 서버용 호환 JAR이 필요합니다. 이 릴리스는 클라이언트 JAR이며 서버용 바이너리를 대신하지 않습니다.

</details>

<details>
<summary>🔎 검증과 적용 범위</summary>

Ed25519 서명, SHA-256, 크기, 클라이언트 빌드를 확인합니다. 수동으로 바뀐 JAR을 덮어쓰거나 이전 빌드로 되돌리지 않습니다. 다른 모드·설정·월드·Prism 실행 명령은 바꾸지 않습니다.

임시 폴더·별도 Java 프로세스에서 업데이트 검증99건을 통과했고, 신규10클래스/98메서드의 Java17 bytecode와 기존335클래스 보존을 확인했습니다. 실제 Minecraft의 새 화면·버튼·재실행 흐름은 별도 게임 검수가 필요합니다.

</details>
