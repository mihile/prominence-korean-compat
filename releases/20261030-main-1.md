사용자가 실사용한 nightly16의 누적 호환·번역 수정을 main 안정판에 통합했습니다. 전리품의 현재 확률과 Shift 계산, 배낭 제작·재단조, 기존 무기·마법부여 호환을 포함합니다.

EMI 목록 생성에 남아 있던 고정1.5초 대기·공용 스레드 우회를 제거하고 기존 main의 원래 게임 스레드 제출을 복구했습니다. 지도 모드 자체 시간 예산과 중복되던250/33ms 갱신 제한도 제거했습니다. 메모리 수명·반복 할당 절감과 최대4Hz 전리품 장비 조회는 유지합니다.
