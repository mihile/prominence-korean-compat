EMI 검색 목록을 준비할 때 해당 아이템과 관계없는 장비 속성 설정을 반복 조회하는 비용을 줄였습니다. 앞선 AzureLib 참조 정리를 포함한 누적 클라이언트 패치입니다.

<details>
<summary>변경 내용과 검증</summary>

- 설치된 Fabric1.20.1 JAR과 해당 EMI/CIA GitHub 소스를 대조했습니다. 검색용 툴팁 생성에서 기존 캐시를 적용한 뒤에도 남은 설정 전체 순회의 비용을 보완합니다.
- 한 번의 검색 준비 중에만 일치하는 설정 객체를 추립니다. ID·목록·순서 변경을 확인하고, 슬롯·NBT·실제 속성/UUID 계산은 원래 코드를 사용합니다.
- 사용자 정의·잘못된 설정·AIR 등은 기존 경로로 처리합니다. 잘못된 ID가 있을 때 이전 항목의 적용과 오류 순서도 보존합니다.
- 이전 캐시가 켜진 native callback 시험에서 조회 요청60,600→1,200회, 결과·순서·NBT 동일을 확인했습니다. 플랫폼/속성 생성 probe를 사용한 검사이며 전체 게임 개선율이 아닙니다. 기존 누적 기능과 서명 업데이트 도우미를 보존했습니다.
- 관리자용 재사용3분 측정 도구와 소스 검토 절차를 저장소에 추가했습니다. JFR 저장 후 매번 힙 덤프를 수집하고, 클라이언트 종료 후 MAT를 실행합니다. 이 도구는 게임에서 자동 실행되지 않으며 raw기록은 공개하지 않습니다.
- 실제 게임의 전체 EMI 시간·프레임 효과는 아직 미측정입니다. 마법부여·Create의 남은 초기화 비용을 모두 해결했다고 주장하지 않습니다.

</details>
