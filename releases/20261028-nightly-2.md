### FTB Quests 크리에이티브 탭 동기 빌드 락 경합 제거 (build 2026102802)

JFR 실측 분석(`20261028-164441-7b6088`)에서 밝혀진 메인 렌더 스레드 프리징 1위 원인을 완벽하게 해결합니다:

- **원인 분석**:
  - 인벤토리를 닫거나 퀘스트북을 열 때 `ftbquestsfreezefix`의 `LevelReadyMixin.onClose` -> `ClientQuestFile.openGui` -> `DisplayStacksCache.computeMatchingStacks`가 메인 렌더 스레드에서 `ItemGroups.updateDisplayContext(...)`를 호출함.
  - 마침 백그라운드 스레드(`ForkJoinPool.commonPool-worker-1`)가 EMI 크리에이티브 빌드 중 `ModernFix`의 `synchronized (ItemGroup.class)` 모니터 락을 소유하고 있어, 메인 렌더 스레드가 해당 락을 얻으려고 **307.28ms 동안 모니터 락에 블로킹**되어 화면이 완전히 굳는 현상 발생.
- **해결 내역**:
  - `FtbQuestsDisplayStacksCacheMixin`: 렌더 스레드(`Render thread`)에서 아이템 필터링 조회 시 메인 스레드에서의 크리에이티브 탭 동기 강제 빌드를 스킵하여 모니터 락 경합을 원천 차단.
  - `FtbQuestsFallbackStacks`: Search 탭이 아직 백그라운드에서 빌드 중일 경우, `Registries.ITEM` 기반의 안전하고 빠른(0.2ms) 스택 컬렉션을 제공하여 퀘스트 GUI 아이콘 표시가 100% 정상 작동하도록 보장.
- **기대 효과**:
  - 인벤토리 닫기 및 퀘스트 GUI 오픈 시 발생하는 357.5ms 렌더 스레드 프리징 완전 소멸.
