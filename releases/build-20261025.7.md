업데이트 화면을 독립 화면으로 바꿨습니다. **빌드6의 버퍼 정리만으로는 메인 메뉴 겹침이 해결되지 않은 것을 사용자 화면에서 확인했습니다.**

- 부모 메인 메뉴의 render 호출 자체를 제거했습니다. 메뉴 버튼·아이콘을 업데이트 화면 안에서 다시 그리지 않습니다.
- FancyMenu의 공개 제외 API로 업데이트 안내/확인 화면 두 개만 커스터마이징에서 제외합니다. 메인 메뉴와 다른 화면은 유지합니다.
- 배경을 완전히 덮고 자체 업데이트 버튼·내역만 그립니다. 닫으면 원래 메뉴로 돌아갑니다.
- 다운로드·서명·백업·종료 후 교체 및 기존 호환 기능은 그대로입니다.

컴파일·기존 코드 보존·업데이트 회귀·부모 렌더 호출 제거와 실제 FancyMenu 인터페이스의 제외 범위를 확인했습니다. **수정한 GPU 화면의 실제 표시는 아직 미검증**이며, 정적 검사 결과로 화면 문제가 해결됐다고 단정하지 않습니다. 서버는 변경하지 않습니다.
