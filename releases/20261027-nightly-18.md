# 시험판: 차원 이동(포탈) 초고속화 및 첫 접속 모델 락 경합 완화

사용자 실측 프로파일(`2c0bab`) 분석을 기반으로, 차원 이동 시 3.5~4.1초씩 발생하던 셰이더 리로드 동결을 완전히 제거하고 첫 접속 시 핫바 렌더링 락 경합을 해소했습니다.

<details><summary>수정 내용과 검증</summary>

- **차원 이동 시 Iris 파이프라인 캐시 보존 (포탈 로딩 즉시 전환)**:
  - 기존: Iris가 차원 이동(`joinWorld`)마다 `destroyPipeline()`을 호출하여 모든 차원의 파이프라인 캐시를 파괴하고 3.4~4.1초 동안 셰이더를 처음부터 다시 파싱/컴파일함.
  - 수정: `IrisPipelineTimingMixin` 및 `DimensionChangeGate`를 통해 차원 이동 중 불필요한 파이프라인 파괴를 스킵하고 Iris의 `pipelinesPerDimension` 맵에 캐시된 파이프라인을 즉시 재사용하도록 개선했습니다.
  - 효과: 오버월드 ↔ 네더 ↔ 엔드 간 재방문 이동 시 파이프라인 재생성 시간이 **0ms(즉시 전환)**로 단축됩니다. (옵션 메뉴에서 셰이더팩 변경 시에는 정상 리로드 유지)
- **셰이더 전처리 인메모리 RAM 캐시 및 비동기 쓰기 강화**:
  - `ShaderSourceDiskCache`에 `ConcurrentHashMap` 기반 RAM 캐시를 탑재하여 중복 셰이더 전처리를 0ns로 즉시 반환.
  - 디스크 쓰기 큐를 64 → 2,048개로 확장하고 워커를 증설하여 큐 드롭(`droppedQueue`)을 원천 차단.
- **첫 접속 GUI/핫바 렌더링 ModelBakery 락 경합 제거**:
  - 접속 직후 백그라운드 EMI 크리에이티브 그룹 빌드가 `ModelBakery.bakeDefault` 락을 계속 점유하여 렌더 스레드가 핫바를 그릴 때 485ms 동안 정지(2~14 FPS)되던 문제를 해결했습니다.
  - EMI 크리에이티브 백그라운드 빌드를 접속 1.5초 후 비동기 실행하도록 디퍼하여, 접속 첫 프레임과 핫바가 락 경합 없이 매끄럽게 렌더링되도록 개선했습니다.

오프라인 네이티브 믹스인 변환(65개 시나리오) 및 핵심 호환 클래스 바이트 동일성 보존 검증 완료.

</details>
