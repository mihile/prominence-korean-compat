차원 이동이나 접속 종료 뒤 AzureLib의 애니메이션 변수가 이전 월드를 붙잡는 경로를 정리합니다. 앞선 EMI 중복 검사 개선을 포함한 누적 클라이언트 패치입니다.

<details>
<summary>변경 내용과 검증</summary>

- 월드·플레이어가 바뀔 때만, 이전 클라이언트 월드를 직접 참조하는 native GeoModel의 core query 공급자를 정리합니다.
- 파싱된 애니메이션이 참조하는 변수 객체는 유지합니다. 다음 렌더에서 기존 코드가 새 값을 다시 등록합니다.
- 현재·서버 월드와 사용자 정의·알 수 없는 공급자를 보존하고, 매 프레임 검사나 강제 GC를 추가하지 않습니다.
- 실제 AzureLib 파서/메모이저를 사용한 수명·GC-root 재현, 변수 객체 보존·갱신·종료·다른 공급자 보호, 지문 검사와 기존 호환 기능 회귀 검사를 통과했습니다. 실게임 RAM 회수량은 아직 측정하지 않았습니다.
- 앞선 EMI 변경은 실게임에서 중복 검사876회를 줄였지만, EMI 전체 시간은 감소하지 않았습니다. 시험용 반복 입력의 개선율을 실게임 성능으로 표시하지 않습니다.
- 기존 호환 기능과 업데이트 도우미를 보존합니다. 파일명과 모드 버전1.0.0을 유지하며 클라이언트만 필요합니다.

</details>
