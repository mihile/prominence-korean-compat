# 번역 자료와 리소스팩

`Prominence_II_Korean_Translate.zip`은 기존 Paxi 한국어 통합 팩의 원본 스냅샷이며 통합 JAR의 내장 리소스팩을 만드는 데 사용합니다. 책·언어 파일·아이콘과 원본 크레딧을 포함합니다. `glossary/`는 과거 용어 검수 및 구조물 이름 기록입니다. 파일마다 기준 시점이 다릅니다.

별도 배포 ZIP은 GitHub의 자료 보관 릴리스에 이전 배포 당시의 구성으로 올립니다. 최신 자동 업데이트는 각 릴리스의 클라이언트/서버 통합 JAR을 사용합니다. 세부 사용 범위와 검증 현황은 저장소 `docs/TRANSLATION_UPDATES.md`를 확인하세요.
