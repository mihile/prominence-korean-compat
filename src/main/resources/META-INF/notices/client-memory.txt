Original client-only compatibility lifecycle hook, MIT. Clears only the pinned Iris GLSL concrete-syntax parser cache after successful pipeline construction. Shader output, compiled programs, small AST build cache, cache capacity, settings, Voxy and server behavior are preserved. No forced garbage collection. Native Iris and glsl-transformer code is not redistributed by this module.
The pinned Sophisticated Backpacks unload callbacks are dispatched through weak identity targets instead of global strong per-instance closures. Native callback bodies/arguments, live-target order and integrated-server dispatch are preserved. No native Minecraft or backpack implementation is redistributed; production callbacks are invoked in place.
