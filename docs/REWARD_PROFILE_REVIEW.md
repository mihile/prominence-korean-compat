이번 수정:

- 드롭 보정 자격과 별개로 안전한 일반 재료·확정 드롭·가중치 분포를 서버의 공통 표시 경로에 포함한다. 원래 약탈 조건은 기존 조건 정보와 현재 장비를 결합한다. 알 수 없는 복합 조건·수량·원래 운 가중치는 확률을 지어내지 않고 기존 보수적 표시로 돌아간다.
- 장비의 약탈 조회가 Trinkets/Accessories 경로를 매 프레임 순회하던 비용을 줄인다. 툴팁을 볼 때만 최대4Hz로 조회하고 플레이어 교체·연결 종료에 무효화한다.
- 수신 데이터가 같은 접속에서 바이트까지 같으면 재해석하지 않는다. 해석은 Netty에서, 설치는 현재 연결을 확인한 뒤 렌더 스레드에서 한다. 손상된 수신 뒤 정상 데이터를 다시 받을 수 있다.
- 서버는 리로드별 불변 목록의 직렬화·압축 결과를 재사용한다. 새 목록은 다시 압축하며 크기 제한과 로그인 순서 보호는 유지한다. ID 검증 정규식은 매 항목마다 재컴파일하지 않는다.
- Shift 계산을 기본 경로로 제공하고 ‘추첨식’을 ‘확률 계산’으로 바꾼다. 복수 회 선택은 실제 분포로 ‘한 번 이상 나올 확률’을 계산한다. 평균 수량을 확률로 바꾸지 않는다.

확대된 서버 데이터는 client2026102916 / server2026102905 조합이 필요하다. 전체 새 목록의 실제 개수·게임 UI는 다음 사용자가 정상 실행한 접속에서 검증한다. 드롭 보정 계수와 자격 정책 자체는 변경하지 않았다.
