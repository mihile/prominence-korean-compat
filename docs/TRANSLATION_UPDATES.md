# Translation corrections delivered with the JAR

Starting with client build2026102608, reviewed language-key corrections are included in `src/main/resources/assets/prominence_korean_compat/translation_overrides/ko_kr.json`. Keep this a cumulative, small correction table rather than copying the full base Korean resource pack. The initial 12 keys correct Obsidilith's location name, the brimstone nectar tooltip, Croptopia calamari ingredients and S'kellak dialogue.

Minecraft loads its normal language resources, including the existing Paxi pack, first. A client-only mixin merges these reviewed keys immediately before the final immutable LanguageStorage map is created. Only a final selected language of `ko_kr` enables the merge. English and other languages remain unchanged. Native numeric placeholder normalization is preserved. Malformed/missing correction data retains the original loaded translations. Exact Minecraft 1.20.1 language-storage hash and MixinExtras 0.5.4 are required; mismatch disables the module. Advanced opt-out: `-Dprominence.translationOverrides=false`.

The existing `quest_reviewed_text.json` exact-line overlay continues to handle supported FTB quest prose. When adding a correction, include the current Korean and official English variants, and update previous mapping values when the preferred wording changes. Do not blindly replace matching words in unrelated quests or alter quest IDs, tasks, rewards or progress data. Text outside language keys and existing quest hooks needs an explicit display integration; it is not automatically covered by this table.

Future workflow: review source/context, update the cumulative correction table or quest prose rules, validate placeholders and the native Mixin/runtime data fixture, build from the latest cumulative JAR, then publish a new internally numbered signed GitHub release. Keep the JAR filename and mod version 1.0.0. Users receive those corrections through the existing approved JAR updater after game exit and restart. They do not need a separate Paxi pack update for these corrections.

The base Korean translations and icons still reside in the integrated Paxi resource pack. Full-pack release maintenance can mirror the reviewed text there. No pack ordering, options, external files, server configs, images or quest gameplay data are changed by the updater. The updater still replaces only its own JAR. This client-only display module does not require a new server release.

Verification: actual native language factory reads a simulated old Paxi JSON resource, then the transformed code changes the outdated calamari name while preserving its unrelated text. Native lookup, containsKey, fallback, English isolation, reload and RTL behavior are checked without starting Minecraft, a world or graphics.
