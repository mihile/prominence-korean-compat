# First-join Voxy renderer timing

The 2026-10-27 recording captured the exact call chain at 06:25:18 UTC: `ClientLodReceiver.tick` → `voxy$createRenderer`. At 06:25:20, the same capture shows `IrisRenderingPipeline.beginLevelRendering` → `LevelRenderer.allChanged` → `voxy$reloadVoxyRenderer` → `VoxyRenderSystem.shutdown`. The installed Iris bytecode initializes the block ID maps and calls the native world-renderer reload before the `activeTexture` instruction where Voxy's existing Iris hook calls `voxy$ensureRenderer`.

Client build 2026102707 wraps just VoxyServer's early creation call. When an Iris shader pipeline is active it defers creation to Voxy's existing first-frame hook. With shaders disabled the original VoxyServer call runs exactly once, including its native errors. The receiver's connection verification, handshake, queue, dimension/session and remote ingest paths are unmodified. The renderer is still shut down on real world/pipeline reloads and closes by existing Voxy code. No OpenGL work is moved to another thread and no resource is reused across invalidation.

The optional patch checks exact installed Minecraft 1.20.1, MixinExtras 0.5.4, VoxyServer 1.2.4+1.20.1-port.3, Voxy 0.2.20-beta+1.20.1-port.9 and Iris 1.7.6+mc1.20.1 versions and hashes. The user's installed filenames still have older port numbers; internal metadata and class hashes establish the actual versions. A mismatch disables this patch. Use `-Dprominence.emiHome.voxyEarlyRenderer=false` to opt out.

`tools/verify_voxy_early_renderer.py` transforms the actual native VoxyServer receiver with Mixin and MixinExtras, runs ASM checks on all transformed methods, checks that the original call is wrapped and that other native tick calls and the ingest drain call list are unchanged, and checks the actual Iris bytecode reload-before-hook ordering. Guard drift and shader/non-shader paths are exercised without launching Minecraft or OpenGL. The earlier 485 classes except the intentionally changed guard, and the updater helper/key, were preserved byte-for-byte. Existing regression checks pass. This does not prove first-frame visual behavior or performance in a real game; verify Iris shaders on/off, LOD delivery, reconnection, dimension changes, F3+A and resource/shader reload after installation. Do not call the entire 9.5-second PresentMon gap the time saved.
