잿불 코인: 바즈 귀속 화폐. 레이드 결과·거래·제작·전리품·FTB 퀘스트 명칭을 통일했습니다.

OP 2 이상 또는 서버 콘솔에서 `/prominence cinder 4`로 모래시계 레이드 보상을 4배로 설정합니다. `/prominence cinder`는 현재 배수 조회, `/prominence cinder 1`은 기본값 복구입니다. 범위는 1~1000입니다. 명령 실행 시 config/prominence-cinder.properties에 저장하며 다음 시작에도 유지합니다.

각 레이드의 정산 시 배수를 고정합니다. 원래 총 코인 보상(기본 및 승급 보너스)에 적용하며 결과창에는 기본 수량과 노란색 ×배수를 표시합니다. 예: 기본 2, 배수4 → 2 ×4 표시, 8 지급. 바즈 거래·주간 퀘스트·임의 코인 추가 명령은 배수 대상이 아닙니다.

멀티플레이 실제 보상 및 명령은 서버용 통합 JAR이 필요합니다. 클라이언트용 JAR은 명칭과 배수 표시를 제공합니다. 구형 클라이언트에는 최종 수량을 그대로 표시합니다. 서버 재시작은 관리자가 직접 하며 실행 중 JAR을 교체하지 않습니다.
