# CaramelChat and FTB single-line text input

Client build2026102701 adds a Windows-only bridge for installed CaramelChat 1.2.2 and FTB Library 2001.2.12 / FTB Quests 2001.4.18 on Minecraft 1.20.1. Exact native class hashes and MixinExtras 0.5.4 are required. Version/hash mismatch or `-Dprominence.ftbIme=false` disables the module. These mods remain optional to the compatibility JAR; unsupported/missing versions do not load this integration.

FTB Quests Ctrl+F calls `QuestScreen.openQuestSelectionGUI`, which opens `SelectQuestObjectScreen`, an `AbstractButtonListScreen` with an FTB `TextBox`. It does not use Minecraft's standard edit box. CaramelChat's standard edit-box and EMI adapters do not register an IME operator for that widget. The upstream issue reports the same custom-widget integration gap: https://github.com/LemonCaramel/caramelChat/issues/30 (different Minecraft/loader version; local bytecode was separately verified).

The new original adapter implements CaramelChat's existing public wrapper API for the FTB TextBox. Focusing the widget enables its existing native operator. Preview updates its display buffer without calling `onTextChanged`, moving the original insertion/selection anchor, or rejecting an unfinished syllable. Completion uses FTB's original `insertText`, retaining its validation, length limit and search callbacks. Native edits/paste/cursor changes synchronize the committed origin. The composition caret and candidate rectangle track the visible text and scrolling. Closing widgets clears focus and cancels unfinished preview.

The same integration covers other FTB single-line TextBox fields. It does not replace the UI, keyboard driver, keybindings, CaramelChat DLL, chat/EMI adapters or FTB multiline editor. A weak target prevents an IME operator from keeping an old FTB screen or world alive. Only the client JAR changes; no server or resource-pack update is required.

Verification applies both mixins to actual FTB TextBox/Widget bytecode (116 verified methods) and verifies the Ctrl+F search hierarchy. Original keyboard/character/validation methods are retained, and commits still delegate to native FTB insertion. A separate CPU fixture uses the actual installed CaramelChat AbstractIMEWrapper with the production adapter, replacing only its Main/native controller with a test-only facade: 32 Korean composition, commit, selection, length/validation, focus, closure and weak-lifetime checks. No native library, Minecraft process, world, graphics or OS IME is started by these tests. Actual Windows IME interaction still needs a gameplay check after updating/restarting.

The source, binary and DLL of the original CaramelChat/FTB mods are not redistributed by this module. CaramelChat is LGPL-3.0; FTB native classes used for local inspection/verification are provided by the user's installation. The bridge itself is original MIT code.
