# 방어구 주입 교체

Eldritch End Fabric 0.3.4는 `canSwapInfusionTo()`의 기본 빈 목록을 모든 재료에서 그대로 사용한다. `InfusionSmithingTableMixin`은 이미 주입된 장비를 거부하여 에티르로도 바꿀 수 없었다. 원본의 다른 제거 레시피/설정은 확인되지 않았다.

대장장이 작업대에서 새 주입의 형판 + 기존 주입 방어구 + 새 재료를 사용한다. 에티르 형판과 주괴를 쓰면 타락 주입을 타락 저항으로 바꾼다. 심장/사지/크살/에티르 사이의 교체를 지원하며 기존 재료는 반환하지 않는다. 주입이 전혀 없는 상태로 지우는 기능은 추가하지 않았다.

교체 결과는 입력의 복사본에서만 만든다. 알려진 이전 재료의 속성이면서 Name=`Infusion modifier`, 현재 방어구 Slot까지 일치하는 NBT 항목만 제거한다. 그 외 속성, 인챈트, 재단조, 이름, 내구도, 유물 진행, 부가 주입 메타데이터는 보존한다. 알 수 없는 재료/소유 정보 누락/동일 재료 재주입은 가로채지 않는다. 원본의 형판·방어구 허용 여부·설정과 원본 재료 소모 경로를 유지한다.

단순히 교체 허용 목록만 열면 원본의 append-only 속성 병합 때문에 기존 타락 효과나 다른 속성이 중복될 수 있다. 결과 생성만 보완하며 최초 주입·일반 대장장이 레시피는 원본에 맡긴다. `priority=900`은 실제 원본 Mixin과 함께 변환하여 원본 결과 생성보다 먼저 실행됨을 검증했다.

Minecraft 1.20.1 / Eldritch End 0.3.4의 원본 클래스 11개 지문이 맞을 때만 활성화한다. 클라이언트와 서버 공통 모듈이며 멀티플레이 판정은 서버에도 같은 기능이 있어야 한다.

검증 도구: `tools/verify_infusion_native.py`(원본 모드 공존·호출 순서·원본 소모 코드), `tools/verify_infusion_fixture.py`(실제 NBT와 독립 장비/레지스트리 fixture, 183개 검사). 실제 게임/월드는 실행하지 않았다.
