# 주문 스킬의 아이템 사용 키 분리

Spell Engine 0.15.12+1.20.1의 SpellHotbar.update가 키 목록을 가져온 직후 실제 해석된 키가 아이템 사용 키 또는 우클릭인 바인딩을 제외한다. 남은 순서를 그대로 사용하므로 기본 USE_KEY, 2, 3, 4, 5 구성은 주문 스킬 4개에 2, 3, 4, 5를 배정한다. 커스텀 비충돌 바인딩은 보존한다.

아이템 사용 모드, 장비 우클릭 및 보조 손 사용 처리는 변경하지 않는다. 슬롯 배정 이전에 필터하므로 HUD와 발동이 동일한 슬롯 정보를 사용한다. 9개 바인딩 중 기본 우클릭 하나가 빠지면 주문 단축키는 최대 8개다.

설치된 SpellHotbar와 WrappedKeybinding 지문을 기존 클라이언트 가드에 추가했다. 네이티브 Mixin 변환 7개 대상/135개 메서드의 바이트코드를 검사하고, 필터가 슬롯 배정 전 호출되는지 확인했다. 기존 쿨타임 실행 검사도 통과했다. 실제 게임 입력은 미검증이다. 서버 수정은 필요하지 않다.
