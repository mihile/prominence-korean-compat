# main 승격 전 성능 검토 — 2026-10-30

기준은 사용자 실사용이 확인된 nightly20261029.16이다. 최신 로그에서도 build2026102916 적용, 서버 확률2,322묶음/685개 표 수신을 확인했다. EMI 전체 초기화19,243.7ms, 최초 입장 Iris1,291ms, 엔드 이동 Iris3,856ms가 남는다. 직전 측정과 통제된 A/B가 아니므로 감소율을 계산하지 않는다. 최신 로그의28 ERROR/1,066 WARN도 검토했으며 오류를 필터링하거나 기존 프로파일 로그와 혼동하지 않았다.

## 철회한 실행 경로

1. `EmiCreativeTimingMixin`의 고정1.5초 대기와 공용 ForkJoinPool 제출을 제거했다. creative 콜백은 다른 모드의 레지스트리·모델·클라이언트 상태까지 호출할 수 있다. 이전 main은 게임이 지정한 executor를 사용했으며 그 방식을 복구했다. 기존 측정의2.7~3.5초 index 단계에 고정 대기가 들어가 있었지만, 제거한 대기 전체를 게임 프레임 개선량으로 환산하지 않는다. 비동기 실패 뒤 콜백을 다시 호출하는 경로도 없어졌다. 그룹별20ms 이상 계측만 유지한다.
2. `XaeroMapWriterTimingMixin` 등록을 해제하고 해당 지문 검증도 기동 때 건너뛴다. 설치된 WorldMap1.47.0 `MapWriter.onRender`에는 타일 수·전체 갱신 목표·지난 쓰기 시각·프레임 여유·쓰기 시간 상한을 반영하는 원래 예산이 있다. 외부250ms/33ms 제한은 이 계산 바깥에서 메서드 전체를 생략했다. native 검토상 지연된 호출은 지난 시간만큼 타일 작업을 모을 수 있어 평탄화 효과를 보장하지 않는다. 프로파일의 MapWriter70 CPU 표본은 비용이 있다는 증거이지 이 추가 제한이 유익했다는 A/B 증거가 아니다. 원래 스케줄링과 지도 상태 검사·쓰기·예산을 복구했다.
